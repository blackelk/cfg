# Writing markdown

-   Use semantic line breaks. Lines are broken by meaning, often at punctuation and conjunctions.
-   Use - for unordered list items: normal dash plus three spaces.
-   Use fenced code blocks with language identifiers where possible.
-   Prefer normal Markdown links like [text](url).
-   Use single backticks for inline code.
-   Avoid trailing spaces and backslash line breaks.
-   Keep headings ATX-style with #, ##, etc.
-   Align Markdown table column separators (|) vertically for readability.
